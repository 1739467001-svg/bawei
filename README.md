# 台风·巴威 BAVI 2026 · 数字模拟

一个纯前端、零依赖的 **程序化台风视觉模拟**，重建 2026 年第 9 号超强台风「巴威 / Bavi」——今年暑期西北太平洋最强台风——从生成到逼近闽浙沿海的整个生命史。

画面不是地图、也不是地球视角，而是 **以台风自身的俯视云系形态呈现**：螺旋雨带、眼墙、台风眼、风场矢量，全部由代码实时生成，并**跟随台风真实强度的演变而实时改变**。

## 直接打开

浏览器打开 `index.html` 即可（单文件，无需服务器、无外部资源）。

## 你能看到什么

- **螺旋云系**：对数螺旋雨带随强度收紧、增多、增亮，北半球逆时针旋转。
- **台风眼 & 眼墙**：强度越高，风眼越小越干净（巅峰期呈"针眼"），眼墙亮环呈现"体育场效应"。
- **风场矢量**：切向风环随半径与强度变化。
- **强度联动主题**：UI 主色随分级切换——热带风暴（青）→ 台风（橙）→ 强台风（红）→ 超强台风（紫）。
- **时间轴**：可播放 / 拖动 / 变速（0.5×–4×），底部同步显示 **风速–气压演变曲线**。
- **图层开关**：红外增强、风场矢量、经纬网格。

## 技术

- HTML5 Canvas 2D，原生 JavaScript，无任何第三方库。
- 关键帧数据线性插值 + 缓动，驱动所有可视化参数（眼半径、螺旋紧致度、旋转速度、亮度、尺度、配色）。
- 加法混合（`lighter`）叠加软粒子精灵生成云带质感；径向渐变挖出台风眼澄空。
- 自适应 DPR 与窗口尺寸，支持鼠标与触摸。
