# 台风·巴威 BAVI 2026 · 三维数字模拟

一个纯前端、零依赖的 **可自由旋转的三维程序化台风模拟**，重建 2026 年第 9 号超强台风「巴威 / Bavi」——今年暑期西北太平洋最强台风——从生成到逼近闽浙沿海的整个生命史。

画面不是地图、也不是地球视角，而是 **以台风自身的立体形态呈现**：用鼠标/手指自由旋转（前后左右上下），从任意角度观察它的**眼墙塔、台风眼、螺旋雨带与砧状云盖**，全部由自研的 Canvas 2D 三维粒子引擎实时生成，并**跟随台风真实强度的演变而实时改变**。

## 直接打开

浏览器打开 `index.html` 即可（单文件，无需服务器、无外部资源、无第三方库）。

## 操作

- **拖动**（鼠标 / 单指）：旋转视角（yaw + pitch）。
- **滚轮 / 双指捏合**：缩放；右下角 `+ / −` 亦可。
- **自动旋转 / 海面网格 / 视角复位**：右下角开关。

## 你能看到什么

- **三维螺旋云系**：数千枚云粒子构成的对数螺旋雨带，臂间留暗缝，北半球逆时针旋转。
- **眼墙塔 & 台风眼**：眼墙是围绕台风眼升起的立柱（向上外扩＝体育场效应）；从侧面可见"砧状云"侧剖面，从上方可见暗色眼洞。
- **强度联动**：强度越高，眼越小、塔越高、螺旋越紧、云系越亮。
- **强度联动主题**：UI 主色随分级切换——热带风暴（青）→ 台风（橙）→ 强台风（红）→ 超强台风（紫）。
- **时间轴**：可播放 / 拖动 / 变速（0.5×–4×），底部同步显示 **风速–气压演变曲线**。

## 技术

- HTML5 Canvas 2D，原生 JavaScript，无任何第三方库（零依赖、CSP 安全）。
- **自研三维粒子引擎**：手写透视投影 + 画家算法深度排序 + 空气透视衰减，把约 3600 枚粒子按「低层雨带 / 眼墙塔 / 砧状云盖 / 外围卷云」四组组织成立体台风。
- 轨道相机：yaw/pitch 旋转、透视缩放、自动旋转、罗盘指北。
- 关键帧数据线性插值 + 缓动，驱动所有可视化参数（眼半径、塔高、螺旋紧致度、自转速度、亮度、尺度、配色）。
- 加法混合（`lighter`）叠加软粒子精灵生成云带质感与辉光；y=0 平面绘制海面极网格与台风眼澄空。
- 自适应 DPR 与窗口尺寸，支持鼠标、滚轮与多点触摸。
